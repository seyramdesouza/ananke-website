## 5. Content model

All content is plain files in `src/content/`, editable in the CMS. Field names match `src/content.config.ts` and `public/admin/config.yml`.

| Content type | Fields |
|--------------|--------|
| **Issue** (`issues/*.md`) | label, numeral, number, year, status (published / forthcoming), summary, standfirst, cover, coverAlt, pdf, pdfSize, publisher, place, ISSN, readUrl, editors[], sections[], credits[], copyright, acknowledgements[], excerpts[], closingQuote. The body holds the editor's note. |
| **Work** (`works/*.md`) | title, titleTranslation, issue, section, page, contributors[], form, order, image. The body holds optional text. |
| **Person** (`people/*.md`) | name, roles (Contributor / Editor / Founder), roleTitle, country, practice, photo, order, links[]. The body holds the bio. |
| **Exhibition** | title, status (current / upcoming / past), dates, venue, artists[], image, summary, curatorial text |
| **Research project** | title, status (ongoing / complete), summary, collaborators[], file |
| **Community project** | title, partners[], location, dates, image, summary |
| **Settings** | `site.json`: name, tagline, description, location, email, Instagram. `open-call.json`: status, issue, theme, deadline, note. |

## 6. Design direction

**Reference:** [Eagle's Nest](https://eaglesnest.webflow.io/), adapted for Ananke. The look:
- warm cream pages and deep forest-green ink
- oversized display-serif headlines with a clean grotesk for text
- pill buttons and 8px-rounded images
- a full-screen hero with a giant title
- sticky stacked panels
- a dark footer with a giant wordmark

### Logo

- **The mark:** a capital A whose centre forms a torch and flame, supplied by Ananke. It's stored once as `public/images/logo.png` (transparent PNG).
- **Colour:** it's drawn as a mask, so it takes the colour around it: forest-green on cream, cream on the dark hero and footer.
- **Where it appears:**
  - the header (with "Ananke *Projects*")
  - the footer (large)
  - the homepage hero (very large and faint)
  - the browser tab icon (`favicon-32.png`)
  - the phone home-screen icon (`apple-touch-icon.png`, `icon-512.png`)
  - the social share image (`og-image.png`: cream mark on forest)
  - the CMS login screen
- **[TBC]:** an **SVG** version would stay sharp at any size.

### Typography

| Role | Font | Notes |
|------|------|-------|
| **Display** | Fraunces (variable, opsz 144) | Free stand-in for PP Pangaia. Used for headings, giant titles, quotes and drop caps. |
| **Text / UI** | Inter Tight (variable) | Free stand-in for PP Neue Montreal. Used for body text, navigation, labels and buttons. |

Both fonts are self-hosted through Fontsource. To switch to licensed Pangram Pangram fonts, change `--display` and `--sans` in `src/styles/global.css`.

## 7. Build and hosting

### Framework and languages

| | |
|---|---|
| **Framework** | [Astro](https://astro.build) 7, static output (plain HTML, CSS, JS and images, with no server) |
| **Node.js** | 22.12 or newer (pinned in `.node-version`; the local machine has Node 24) |
| **Page structure** | HTML, inside `.astro` files |
| **Design** | CSS (`src/styles/global.css`, plus styles in each component) |
| **Content** | Markdown (issues, works, people) and JSON (settings) |
| **Interactions** | Small amounts of JavaScript (mobile menu, header colour change, reveal-on-scroll) |
| **Extras** | `@astrojs/sitemap` for the sitemap, Fontsource for the fonts |

**Commands:**

```bash
npm run dev
```

```bash
npm run build
```

`npm run dev` gives a local preview at http://localhost:4321. `npm run build` writes the finished site to `dist/`. The README has the full command list.

### Editing dashboard: Decap CMS (free)

- **Address:** https://anankeprojects.com/admin. Editors log in with GitHub, and changes are saved as files in the repository. Cloudflare then republishes the site within a minute or two.
- **Editorial workflow:** changes go through Draft → In Review → Ready.
- **Dashboard sections:**
  - **Issues:** including sections, credits, excerpts, closing quote, cover alt text, PDF and file size
  - **Works:** including section, page number and translated title
  - **People**
  - **Exhibitions**
  - **Research**
  - **Community Projects**
  - **Settings:** Open Call, and Site Settings (including location)
- **Login:** GitHub login runs through two Cloudflare Pages Functions in `functions/api/` (`auth.js`, `callback.js`). They need `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET` as environment variables in Cloudflare.
- **Local editing:**

  ```bash
  npm run cms
  ```

  Run this alongside `npm run dev`, then open http://localhost:4321/admin/.
- **Repository:** [github.com/seyramdesouza/ananke-website](https://github.com/seyramdesouza/ananke-website), set in `public/admin/config.yml`.
